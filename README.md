# Metropolis Next - Smart City Information Portal

A responsive and interactive web portal showcasing smart city initiatives, public utility services, real-time public transit schedules, and municipal grievance logging.

## Project Title & Objective
- **Title**: Metropolis Next Smart City Portal
- **Objective**: To provide citizens with a unified digital platform providing access to urban development initiatives, live public transit and air quality metrics, municipal public services, and interactive citizen reporting.

## Key Features
- **Key Urban Initiatives Directory**: Categorized grid with interactive dynamic filtering (IoT, Mobility, Clean Energy).
- **Live Transit & Environment Hub**: Simulated live timetable for rapid transit lines with refresh capabilities and AQI monitoring telemetry.
- **Citizen Digital Services**: Direct access points for utility billing, smart parking, and emergency response.
- **Interactive Grievance Registration**: Client-side validated form generating uniquely tracked ticket IDs upon submission.
- **Responsive Layout**: Designed for mobile devices, tablets, and wide monitors.

## Technologies Used
- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Responsive flexbox and CSS grid layouts, CSS custom variables, keyframe animations, and media queries.
- **JavaScript (ES6)**: DOM manipulation, dynamic category filtering, scheduled status simulation, animated statistical counters, and form validation.
